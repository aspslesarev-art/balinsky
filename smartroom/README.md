# Smart Room — гостевой портал отеля на своём сервере

Гость сканирует QR в номере → открывается страница отеля: пишет на стойку и
заказывает услуги. Персонал работает в панели `/desk`. Всё крутится на вашем
сервере: ни Supabase, ни Vercel, ни внешней базы. Данные — файлы в `./data`.

## Запуск

```bash
cd smartroom
npm install
node server.mjs
```

→ `http://localhost:3000/admin` (пароль по умолчанию `admin123`).

При первом запуске заводится демо-отель: код отеля `demo`, код смены `1234`,
три номера с готовыми QR-ссылками — они печатаются в консоль при старте.

### На сервере в сети

```bash
ADMIN_PASSWORD='свой-пароль' \
PUBLIC_URL='http://192.168.1.50:3000' \
SESSION_SECRET='любая-длинная-строка' \
node server.mjs
```

`PUBLIC_URL` обязателен, если сервер открывают не с самой машины: этот адрес
зашивается в QR-коды. Оставите `localhost` — телефон гостя по QR никуда не
попадёт.

### Docker

```bash
cp .env.example .env    # поправить HOST_PORT, PUBLIC_URL, пароль
docker compose up -d --build
```

`HOST_PORT` — порт на хосте. На сервере, где уже живёт Home Assistant, 3000
нередко занят (Grafana, Node-RED), а 8123 — сам HA, поэтому в примере 3080.

Данные лежат в `./data` рядом с проектом — том примонтирован, переживает
пересборку. Бэкап = скопировать эту папку.

### Автозапуск через systemd

```ini
[Unit]
Description=Smart Room
After=network.target

[Service]
WorkingDirectory=/opt/smartroom
ExecStart=/usr/bin/node server.mjs
Environment=PUBLIC_URL=http://192.168.1.50:3000
Environment=ADMIN_PASSWORD=свой-пароль
Environment=SESSION_SECRET=длинная-строка
Restart=always

[Install]
WantedBy=multi-user.target
```

## Три экрана

| Экран | Адрес | Кто входит |
|---|---|---|
| Гость | `/stay/<токен>` | никто — токен из QR и есть доступ |
| Стойка | `/desk` | код отеля + код смены |
| Админка | `/admin` | пароль из `ADMIN_PASSWORD` |

## Как подключить отель

1. `/admin` → «+ Отель», задать название, WhatsApp и Telegram ресепшн.
2. Вставить список номеров пачкой — на каждый заведётся свой токен.
3. Собрать каталог: категории по разделам, внутри позиции с ценой.
4. «QR на печать» → распечатать, разрезать, разложить по номерам.
5. Отдать стойке код отеля и код смены — вход на `/desk`.

## Что внутри

- `server.mjs` — HTTP, API, хранилище, генерация QR. Одна зависимость (`qrcode`).
- `public/guest.html` — портал гостя: каталог по разделам, форма заявки, чат.
- `public/desk.html` — стойка: номера, непрочитанные, заявки, «Выезд».
- `public/admin.html` — отели, номера, каталог, счётчики, выгрузка CSV.
- `data/hotels.json`, `data/threads.json`, `data/events.json` — все данные.

## Что важно знать

- **Смена гостя — разделитель приватности.** Переписка и заказы висят на
  заезде: нажали «Выезд» — следующий гость по той же наклейке видит чистый
  лист.
- **Токен в QR — и есть ключ.** Плата за «отсканировал и пишешь» без
  регистрации. Утёк — «новый код» в админке, старая наклейка мертва.
- **Что заказали, решает каталог, а не браузер гостя:** название и цена
  берутся с сервера по id позиции.
- Заявка обязательно требует WhatsApp (минимум 6 цифр) — по нему отель
  подтверждает заказ.
- Каждое действие гостя пишется в `data/events.json`; выгрузка CSV в админке.

## Чего пока нет

Автоперевода чата (стойка отвечает на языке гостя сама), оплаты, интеграции
с PMS, загрузки фото файлами (фото задаются ссылкой), уведомлений стойке в
Telegram.
