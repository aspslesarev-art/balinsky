# Ролик партнёрской программы (/phuket-partners)

Минутный ролик-питч для агентов Пхукета: озвучка + анимированная карта-курс
Пхукет → Бали, схема партнёрки, условия старта, тур.

## Что где

| Файл | Что это |
|---|---|
| `scene.html` | Сама сцена. Открывается в браузере как обычная страница — можно смотреть и править вживую. |
| `voice.mp3` | Озвучка, 60.26 с (ElevenLabs, голос «Андрей»). Тайминги сцен привязаны к ней. |
| `render.mjs` | Покадровый рендер сцены + сведение с озвучкой в mp4. |

## Пересборка

```bash
node scripts/pitch-video/render.mjs          # pitch.mp4  1920×1080, тёмный — в герой лендинга
node scripts/pitch-video/render.mjs --reel   # reel.mp4   1080×1920, светлый — под Instagram Reels
```

Нужны `ffmpeg` в PATH и chromium для Playwright (`npx playwright install chromium`).
Рендер — около минуты на ролик.

Готовый горизонтальный ролик кладётся на сайт руками:

```bash
cp scripts/pitch-video/pitch.mp4 public/phuket-partners/pitch.mp4
ffmpeg -y -i public/phuket-partners/pitch.mp4 -ss 4 -frames:v 1 \
  -vf scale=1280:-2 -q:v 4 public/phuket-partners/pitch-poster.jpg
```

Вертикальный `reel.mp4` на сайт не идёт — его загружают в Instagram напрямую.

## Как устроена анимация

Состояние сцены — **чистая функция времени**: `window.__seek(t)` расставляет
прозрачности и сдвиги на момент `t`. Отсюда два следствия.

Во-первых, рендер идёт по виртуальным часам с точным шагом 1/30 с, а не записью
экрана: запись роняет кадры и уплывает от звука, здесь рассинхрон невозможен.

Во-вторых, на живой странице те же вычисления привязаны к `currentTime` тега
`<audio>` — поэтому веб-версия и mp4 режутся ровно на одних и тех же словах,
а перемотка попадает в кадр.

**Из-за этого анимацию нельзя переводить обратно на CSS-переходы** — они идут по
реальному времени и при покадровой съёмке схлопнутся в резкие скачки.

## Правки

Тексты, тайминги сцен и порядок появления блоков живут прямо в `scene.html`:
у каждого элемента атрибут `data-at` — секунда, на которой он появляется,
у секции ещё и `data-until`. Тайминги сняты по границам фраз озвучки.

Вертикальная светлая версия — это тот же макет, а не копия: режим `?mode=reel`
переопределяет только токены палитры и кегли (блок `:root.reel` в стилях).
Правка текста автоматически попадает в обе версии.

**Дата дедлайна «17 августа» нарисована в кадре.** При смене условий её надо
поменять в `scene.html` (сцена `data-at="36.86"`) и пересобрать оба ролика.
Счётчик оставшихся дней там же считается от `2026-08-17` — правится рядом,
в блоке `deadline countdown`.
